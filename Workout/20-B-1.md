## 2. P1：对话内媒体生成

### 2.1 前端交互

`MediaPromptSelector` 提供图片/视频页签：

- 图片覆盖 17 个 WEBSEC-101 知识点。
- 视频对 HTTP、SQL 注入、反射型 XSS、CSRF、SSRF、OWASP Top 10 使用后端同主题的详细预设，其余知识点使用受控教学模板。
- 支持搜索、选择知识点和自定义描述；选择后在输入区显示媒体类型与 `kp_id`。

发送媒体请求后不进入普通 tutor SSE：

1. 创建用户媒体请求消息和助手占位消息。
2. 记录“解析请求、调用实时媒体服务、安全加载媒体”等基础设施活动。
3. 图片等待单次生成响应；视频提交后每 5 秒轮询，最多 120 次。
4. 刷新时将未完成媒体任务恢复为显式停止/失败状态，不伪装继续运行。
5. 停止使用 `AbortController`；重试复用原请求，不创建普通聊天请求。

普通文本聊天路径已单独回归，工作流不可用时仍显示既有“演示生成 / 演示数据”边界和“智能体工作记录”。

### 2.2 媒体渲染

- 图片：鉴权请求后创建 Blob URL，卸载或资源变化时回收；支持点击放大、背景点击关闭与 `Escape` 关闭。
- 视频：鉴权请求后创建 Blob URL，使用原生播放器、`controls`、`playsInline` 和 `preload="metadata"`。
- 元信息：模型、提供方、尺寸、时长、文件大小、生成耗时和知识点；仅实时生成结果显示实时来源，本地教学视频不显示额外来源标签。
- 失败态：展示后端友好错误、工作活动失败节点和“重试生成”按钮。
- 进度态：在网络请求返回前立即展示图片/视频骨架和当前基础设施动作。

### 2.3 视频 API

```text
POST /api/v1/media/generate-video
GET  /api/v1/media/video-status/{local_task_id}
GET  /api/v1/media/video-assets/{asset_filename}
```

本地任务和资源路径：

```text
media/tasks/videos/{user_id}/{local_task_id}.json
media/tasks/videos/assets/{user_id}/{asset_filename}.json
media/generated/videos/{user_id}/{kp_id|custom}/{uuid}.{mp4|webm}
```

前端只看到本地 UUID、状态和鉴权资源路径，不接收上游 task id 或下载 URL。完成任务再次查询直接返回持久化结果，不重复下载。

### 2.4 后端安全边界

- API key 只从后端设置读取；缺失/占位时返回 503。
- 上游错误转换为固定友好信息，不回显 key、完整 URL 或原始响应。
- 下载仅允许 HTTPS，拒绝凭据 URL、localhost、`.local`、私网/保留地址。
- 域名解析结果也必须全部为公网地址；最多跟随 3 次逐跳复检的重定向。
- 同时检查声明长度与流式累计大小。
- 通过魔数识别 MP4 `ftyp` 或 WebM EBML，只接受 MP4/WebM。
- 任务、资源索引和媒体对象均按当前登录用户隔离；畸形 UUID 与越权查询统一为 404。

## 3. 唯一一次真实视频提交

在所有普通测试通过后，安全检查确认 `.env.local` 中存在非占位 Wuyinkeji key；检查过程只输出“已配置”和长度，没有输出 key 内容。随后使用供应商官方、不会创建生成任务的 `/detail` 查询做了免费鉴权探测，当前配置的 key 鉴权成功；探测同样没有记录或回显 key。

| 项目 | 结果 |
|---|---|
| 真实提交次数 | **1** |
| 规格 | 10 秒、1280×720、HTTP 请求/响应教学动画 |
| 后端 HTTP 结果 | **502** |
| 友好信息 | `视频生成服务未接受本次任务。` |
| 是否获得本地 task id | **否** |

| 是否重试 | **否** |

该结果不能视为视频生成任务成功，但也不是无效 key：免费 `/detail` 探测已经证明当前 key 可以通过供应商鉴权。唯一一次生成请求已到达后端视频服务并被安全转换，但上游没有接受任务，可能与账户余额、模型权限、请求参数约束或供应商当时的服务状态有关。为遵守单次付费调用边界，首次实施及本次小修验收均没有再次提交。

浏览器中的视频成功态使用仓库内现有教学 MP4 作为确定性夹具，验证前端提交、一次轮询、鉴权 Blob 加载和播放器能力；该夹具没有被标记或汇报为本次上游生成结果。

## 4. P2：VOSviewer 风格图谱

- WEBSEC 节点为真正圆形气泡，直径由资源数和题目数共同决定。
- 10 个章节使用稳定色组；同色密集区域由 DPR 感知 Canvas 密度层叠加。
- 布局由冻结路线坐标作为种子，使用纯 JavaScript 的确定性引力/斥力松弛，不引入随机数或新依赖。
- 边使用 Bezier 曲线；跨章节弱关系为虚线，线宽按权重变化，颜色混合两端章节色。
- 悬停继续使用 BFS 连接路径，高亮完整前驱/后继网络并淡化其他节点。
- 标签根据缩放级别在稀疏章节标签、简称和完整标题间切换。
- 侧栏展示入度、出度、连接度、近似 PageRank、章节资源/题目密度和难度分布。
- 暗色与浅色主题均经过截图目检。

跨课程节点首次加入时，React Flow 会在节点尺寸测量前执行 `fitView`，导致边缘六边形被裁切。本轮将视口重算延后 80 ms，待节点完成测量后再适配；复验时 10 个跨课程节点全部位于画布范围内。

## 8. 2026-08-01 本地教学视频补充

用户使用 Google Omni 独立生成并验收了 HTTP/HTTPS 教学视频，随后将 MP4 放入：

```text
frontend/public/assets/websec/generated/videos/http-basics.mp4
```

Chat 对指定的完整提示词与课程预设执行标准化精确匹配。命中后直接构造前端静态资源 URL，不调用 `POST /api/v1/media/generate-video`，并保持以下真实工作活动：

1. 解析媒体生成请求。
2. 匹配本地课程媒体。
3. 准备本地视频资源。

为避免发送后结果瞬间出现，准备阶段增加 1.6 秒可中止缓冲。浏览器实测约 77 ms 进入准备态，缓冲期间播放器数量为 0，约 1.92 秒完成并显示视频。页面不显示“预生成资源”标签，也不向视频叠加水印或特殊标记；若本地文件缺失则显式失败，不会静默转向付费服务。
