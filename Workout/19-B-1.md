## 2. 火山引擎真实 API 配置

### 2.1 最终接口配置

根据本轮最终联调使用的火山方舟 Agent Plan 接口，Ark API 基址为：

```text
https://ark.cn-beijing.volces.com/api/plan/v3
```

图像生成请求为：

```text
POST /images/generations
```

本实现最终默认模型为 `doubao-seedream-5.0-lite`，请求尺寸使用 Agent Plan 契约支持的 `2K`，输出格式为 PNG，并关闭水印。配置仍可通过环境变量替换。

### 2.2 最终联调状态

早期占位凭据曾返回 `401 AuthenticationError`；随后使用新的后端环境配置完成联调，用户已确认图像生成功能可用。真实密钥只保存在忽略提交的 `backend/.env.local`，没有写入源码、示例配置或本文档。

最终环境配置形式如下：

```dotenv
VOLCENGINE_IMAGE_API_KEY=__VALID_KEY__
VOLCENGINE_IMAGE_MODEL=doubao-seedream-5.0-lite
VOLCENGINE_IMAGE_BASE_URL=https://ark.cn-beijing.volces.com/api/plan/v3
```

## 3. 后端实现

### 3.1 配置

新增配置：

- `VOLCENGINE_IMAGE_API_KEY`
- `VOLCENGINE_IMAGE_MODEL`
- `VOLCENGINE_IMAGE_BASE_URL`
- `VOLCENGINE_IMAGE_TIMEOUT_SECONDS`
- `VOLCENGINE_IMAGE_MAX_BYTES`

`.env.example` 只包含占位符，不包含真实密钥。

### 3.2 API

```text
POST /api/v1/media/generate-image
GET  /api/v1/media/assets/{kp_id}/{asset_filename}
```

生成接口要求真实登录身份。成功后图片写入现有 StorageService：

```text
media/generated/images/{user_id}/{kp_id}/{uuid}.{png|jpg|webp}
```

读取接口按当前登录用户重建对象键，避免跨用户读取；前端通过带 Bearer Token 的 Blob 请求加载，不暴露本地 `file://` 地址。

### 3.3 安全边界

- 只接受 WEBSEC-101 的 17 个冻结知识点 ID。
- 上游下载仅允许 HTTPS。
- 拒绝 `localhost`、`.local` 和非公网 IP，避免模型 URL 形成 SSRF。
- 最多跟随 3 次受检重定向。
- 最大文件 20 MiB，可配置。
- 只接受并通过魔数确认 PNG、JPEG、WebP。
- 上游错误不回显 API key、临时 URL 或完整响应。
- 实时图片必须先持久化，再向前端返回资源路径。

每项包含知识点标题、视觉类型、场景摘要、必需标签、推荐尺寸；公共模板约束攻击载荷抽象化、16:9 构图、中文标签与安全/攻击色彩语义。

## 5. 前端体验

- 课程路线图当前节点下方显示“视觉讲解”。
- 图片与视频分别放在“图解 / 动画”页签。
- 单素材使用更宽的编辑式卡片，多个素材自动两列。
- 卡片元信息栏明确显示“精选图解 / 精选动画 / 实时生成”。
- 点击图片或“查看策划与来源信息”打开详情侧栏。
- 详情展示提供方、模型/管线、尺寸、日期、生成/策划摘要。
- 视频使用原生 `<video controls>`，无需第三方播放器。
- 实时生成使用 `@/lib/api`，成功后以鉴权 Blob URL 展示并在组件卸载时回收。
- 缺精选素材时展示空态；模型未配置时展示真实错误，不替换成演示成功。
- 390 px 视口实测横向溢出为 `0 px`。
