## 2. `/workspace` adapter + fallback

- 原问题：`Workspace.tsx` 的 `TodayCourseCard` 直接 `fetch(${API_BASE_URL}/api/v1/courses)`，失败时静默保留本地默认值，UI 不能区分 loading / error / fallback，也没有统一 adapter 口径。
- 修改方式：新增 `loadTodayCourseSnapshot(course)`，内部使用 `apiGet('/api/v1/courses')`、`AbortController` 4.5 秒超时、payload 规范化与字段校验。网络错误、5xx、502、超时、字段异常降级为 `courseCatalog` fixture；4xx `ApiError` 直接抛给 UI 错误态。
- backend 关闭时表现：今日课程卡片仍展示本地 Web 安全课程 fixture，状态 badge 显示 `fixture 预览`，并显示“真实课程接口网络异常、5xx、超时或字段异常，已降级为 fixture 预览。”。

## 3. navItems / search-data 对齐

- 删除或调整的入口：侧边栏和 GlobalSearch 中 `/workspace?tab=today|ddl|actions|recent|freshness|industry|social|policy` 不再作为 Workspace 主入口。
- 保留的入口：`/workspace` 默认页，以及 `/workspace#today-course`、`#today-tasks`、`#recent-resources`、`#agent-runs`、`#capability`、`#rhythm` 六个可见区域锚点。
- 兼容处理：`CourseStudy` 支持旧链接 `/course?courseId=web-sec&view=resources`，自动归一到 `view=structured&tab=workbench`；`web-sec` 等 legacy courseId alias 归一到 `web-security-foundation`。

## 4. ResourceWorkspace 多资源展示

- 支持的 `resource_type`：`doc`、`ppt`、`mindmap`、`quiz`、`lab`、`readings`、`video`。其中 `video` 前端展示文案标注为 `视频脚本（video_script）`。
- 每类展示组件：继续复用现有 `ResourceTabs` 和资源视图分发，`resourceTypeLabel` 统一标签；资源工作台顶部新增覆盖范围提示。
- fallback 策略：未拿到真实 artifact 时优先使用 `mockResources` fixture，并在标题加 `（演示 fixture 预览）`。SSE artifact 到达时优先采用 `artifact.resource_type ?? targetType`，`onDone` 也用最近 artifact 类型写回，保持 5-B-2 的 artifact payload 优先决策。
